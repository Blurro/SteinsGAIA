This aims to be a full World Line chronology generator where you create the events, set the cause and effect of those events, and this program handles the World Line logic.

With built-in rules, ANY chronology created by this will be rule-accurate, and any unexpected deviation from Steins;Gate would be a user-input error, that's the idea.

Currently not AT ALL user friendly, and so far from complete I might have to just start from scratch when I pick this back up lol. There's so many hurdles and edge cases you never really think about until its time to tell the code how it works...
